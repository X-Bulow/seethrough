# report

The final report is LaTeX in this directory, built with `make` (latexmk; MacTeX or TeX Live).

    make            # build/asg2-final-Cheng_Zefeng+Wei_Yuning+Xu_Ruofan.pdf
    make tables     # regenerate tables/*.tex and tables/*.dat from the committed results bundles
    make watch      # rebuild on every save
    make clean      # remove LaTeX intermediates, keep the PDF

| path | what |
|---|---|
| `src/main.tex` | preamble, title, abstract; `\input`s one file per section |
| `src/01-introduction.tex` … `src/08-conclusion.tex`, `src/appendix.tex` | the sections |
| `src/refs.bib` | bibliography (the proposal's, plus the documentation and projects cited) |
| `tables/` | generated: `scripts/gen.py` (detection tables, plot data, performance tables) and `benchmarks/plot.py` (the `*.csv` summaries); never hand-edited |
| `figures/` | generated by `benchmarks/plot.py`; never hand-edited |
| `build/` | latexmk output; ignored except for the folder itself |
| `part-b.md` | B's chapter notes, the source of §4.2 and §6 |

Before submitting, set `\groupnumber` and `\videolink` at the top of `src/main.tex` (the course
asks for the presentation video link in the report).

Implementation, Annotations, CMA Rewrite, Q1 Analysis; C — Tool Setup, Performance Methodology,
Q2 Results; all — Introduction, Related Work, Discussion, Limitations, Conclusion.
